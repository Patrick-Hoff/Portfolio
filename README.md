## Descrição do Projeto

<p align="justify">
  Meu portfólio pessoal desenvolvido com HTML, CSS e JavaScript tem como objetivo apresentar quem sou como desenvolvedor web, minhas experiências, habilidades técnicas e projetos realizados. Com um layout responsivo e moderno, o site foi planejado para facilitar a navegação e destacar minha trajetória profissional.
</p>

---

## Funcionalidades

✅ **Home:** imagem de apresentação e introdução como desenvolvedor  
✅ **Carrossel:** exibição das tecnologias utilizadas  
✅ **Sobre:** informações pessoais, trajetória e formação  
✅ **Projetos:** lista de projetos com botões para GitHub e deploy  
✅ **Contato:** formulário para envio de e-mails
