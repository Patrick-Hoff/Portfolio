## Seções

- **Hero** — apresentação com efeito typewriter, code card e contadores animados
- **Sobre** — resumo profissional e cards de informações
- **Skills** — tecnologias organizadas por categoria (Front-end, Back-end, Banco de Dados, Ferramentas)
- **Projetos** — 7 projetos com links para GitHub e demo
- **Experiência** — timeline profissional e acadêmica
- **Contato** — links diretos e formulário de contato

## Tecnologias utilizadas

| Camada | Tecnologias |
|---|---|
| Estrutura | HTML5 semântico |
| Estilo | CSS3 com Custom Properties, Glassmorphism, Grid e Flexbox |
| Animações | JavaScript ES6+ puro (IntersectionObserver, typewriter, tilt 3D, parallax) |
| Fontes | Inter + Manrope (Google Fonts) |
| Ícones | Font Awesome + Devicons |
| Formulário | FormSubmit.co |
| Deploy | Netlify |

## Como rodar localmente

```bash
git clone https://github.com/Patrick-Hoff/Portfolio.git
cd Portfolio
```

Abra o `index.html` no navegador ou use uma extensão como **Live Server** no VS Code.
