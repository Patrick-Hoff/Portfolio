ERP para a indústria de embalagens

Sistema web de gestão que desenvolvi para uma fábrica de embalagens de papelão. Centraliza a operação em um fluxo único e rastreável: do orçamento técnico à venda, produção, compras e estoque.

React 18 TypeScript Node.js Express MySQL 8 Tailwind CSS Docker Nginx

Confidencialidade. O ERP foi desenvolvido em ambiente empresarial e seu código-fonte não é público. As telas abaixo são da aplicação demonstrativa independente, escrita do zero e com dados 100% fictícios, para ilustrar o sistema.

    Arquitetura e stack

    Frontend

    React 18, TypeScript, Vite, Tailwind CSS, TanStack Query, React Hook Form, Recharts, React-PDF e dnd-kit.

    Camadas

    pages → hooks → services → cliente HTTP, com design system interno.

    Backend

    Node.js, Express 5 e TypeScript. API REST documentada com Swagger/OpenAPI.

    Camadas

    routes → controllers → services → database, com transações e tratamento central de erros.

    Dados

    MySQL 8 com migrations SQL versionadas e usuário de aplicação com privilégios mínimos.

    Arquivos

    Fotos, layouts e anexos em bucket privado no Cloudflare R2, servidos só pelo backend autenticado.

    Infraestrutura

    Docker com build multi-stage, Docker Compose, Nginx como proxy reverso e deploy no Railway.

    Segurança

    JWT em cookie HttpOnly, bcrypt, Helmet, rate limit no login e validação de entrada.

    Problemas reais

    Desafios técnicos

    Baixa de estoque

    Produtos com e sem composição. A dedução pelos insumos acontece na própria transação da venda, com registro de movimentação.

    Numeração diária

    Orçamentos numerados por dia sem duplicidade: contador travado na transação de criação e índice único.

    Frete na venda

    O frete virava desconto ao editar a venda. Agora o total acompanha a diferença do frete, com validações.

    CPF/CNPJ vazio

    Conflito de unicidade resolvido gravando string vazia como NULL, com migration idempotente de correção.

    Sessão segura

    Token exposto a XSS: JWT movido do localStorage para cookie HttpOnly, com rate limit e algoritmo fixo.

    Upload de PDFs

    PDFs grandes eram recusados pelo proxy. O limite do Nginx foi ajustado acima do limite da aplicação.

    Rode localmente

    Suba a demo com Docker

    1. O MySQL cria as tabelas automaticamente.
    2. A API gera seis meses de dados fictícios coerentes entre si (orçamentos → vendas → estoque → compras).
    3. O Nginx serve o React e repassa /api para a API. Acesse localhost:8080.
    $ git clone https://github.com/Patrick-Hoff/demo_erp.git
$ cd demo_erp
$ docker compose up -d --build
# abra http://localhost:8080
